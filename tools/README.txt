Folder narzędzi administracyjnych.

OfficeScrubber/OfficeScrubberAIO.cmd jest dołączony lokalnie z repozytorium
abbodi1406/BatUtil. Aplikacja pokazuje ostrzeżenie, loguje SHA-256 i uruchamia
narzędzie interaktywnie. Nie uruchamia automatycznie pełnego czyszczenia Office.

MCPR.exe nie jest dołączony. Jest pobierany bezpośrednio z serwera McAfee po
użyciu przycisku „Pobierz i uruchom McAfee MCPR”, a jego SHA-256 trafia do logu.
